\# Django Job Board Platform



A web-based Job Board Platform developed using Django. 

This application allows employers to post jobs and applicants to search and apply for available jobs.



\## Features



\- User Registration and Login

\- User Logout

\- Admin Panel Management

\- Employer can Post Jobs

\- Display Available Jobs

\- Apply for Jobs

\- View Applied Jobs

\- Employer can View Received Applications

\- Bootstrap Responsive UI



\## Technologies Used



\- Python

\- Django

\- SQLite Database

\- HTML

\- CSS

\- Bootstrap
